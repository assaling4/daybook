# Daybook

A personal journal, mood tracker and schedule that works offline on iPhone and PC.

- Open the site in Safari, tap Share, then **Add to Home Screen**.
- Journal entries are stored only on the device. Use **Save backup** in the Journal tab.
- The English checker is [Harper](https://github.com/automattic/harper) 3.0.0 (Apache-2.0), bundled in `h/` and run on the device.
